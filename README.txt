CUP3D
=====

3D incompressible Navier-Stokes solver with adaptive mesh refinement
for flows around swimming fish. C99, MPI, OpenMP, one file: main.c.

BUILD
-----

macOS

    brew install open-mpi gcc make
    OMPI_CC=gcc-15 gmake

FAS RC (Rocky 8, Lmod)

    module load gcc/14.2.0-fasrc01 openmpi/5.0.5-fasrc01
    make

Lookup tables lab_ss*.bin are generated by gen_table.py (make target)
and must sit in the working directory of the run.

RUN
---

    ./run.sh          two fish, local, 2 ranks x 4 threads
    ./300.sh          300-fish school
    sbatch rc300.sh   300.sh on one sapphire node, 28 ranks x 4 threads

All parameters are required on the command line; unknown or repeated
keys abort. Fish are given with -factory-content, one line per fish.

FAS RC, reusable allocation (job steps instead of waiting per run):

    sbatch -p sapphire -N 4 --ntasks-per-node=2 --cpus-per-task=56 \
        --mem=900G -t 3-00:00:00 --wrap 'sleep infinity'
    export OMP_NUM_THREADS=56 OMP_PLACES=cores OMP_PROC_BIND=close
    srun --jobid=JOBID -N 4 -n 8 --ntasks-per-node=2 -c 56 \
        --mpi=pmix --cpu-bind=sockets stdbuf -oL ./main ARGS

srun needs --mpi=pmix with this OpenMPI and explicit -n/-c, otherwise
it starts one rank per node. One rank per socket, threads inside.
Write to /n/netscratch/koumoutsakos_lab/Lab/slitvinov/cup3d, not $HOME.

OUTPUT
------

Every -tdump: vel.NNNNNNNN.{xdmf2,blk.raw,attr.raw,vort.raw}.
blk.raw: per block 6 float32, origin z y x then h h h.
attr.raw: chi, float32 per cell. vort.raw: vorticity, 3 float32 per cell.
Cells within a block are x-fastest, 8x8x8. The XDMF references the raw
files by byte offset; ParaView opens it directly. 16 bytes per cell.

RENDER
------

    python3 tool/iso.py 5 vel.*.xdmf2
        amriso (pip install git+https://github.com/cselab/amriso): body surface
        chi=0.5 and |omega| surfaces at the given levels, as triangle
        meshes vel.N.body.* and vel.N.omegaL.*, colored by omega_z.
    pvpython tool/pvsurf.py 5 vel.*.xdmf2
        renders those to vel.N.surf.png; fixed camera, global color range.
    ffmpeg -framerate 8 -pattern_type glob -i 'vel.*.surf.png' \
        -pix_fmt yuv420p out.mp4
    pvpython tool/pv.py 1,2,4 vel.*.xdmf2
        ParaView-only contours, small dumps only.
    python3 tool/post.py vel.*.xdmf2
        top view of chi, post.mp4.

FAS RC: no ParaView module; use conda env pv
(~/miniforge3/envs/pv: paraview 6.1.1, mesalib, numpy, amriso):

    ~/miniforge3/envs/pv/bin/python3 tool/iso.py 5 vel.*.xdmf2
    ~/miniforge3/envs/pv/bin/pvpython --force-offscreen-rendering \
        tool/pvsurf.py 5 vel.*.xdmf2

pvbatch of that build hangs on login nodes; use pvpython.
